# LV999 Releases

This repository distributes public Windows installers and automatic-update assets for LV999.

Download `LV999-win-Setup.exe` from the latest release. After installation, LV999 checks this repository for signed update packages and downloads an available update in the background. Choose **Restart to update** from the LV999 tray menu when convenient.

Source code, development documentation, build logs, local paths, user data, credentials, and provider sessions are not published here.

## Security

Only download assets attached to GitHub Releases from this repository. Windows code signing will be enabled before the first public production release.
