# LV999 Releases

This repository distributes public Windows installers and automatic-update assets for LV999.

## Current channel: unsigned beta

Download `LV999-win-Setup.exe` from the latest release. Windows may display a Microsoft Defender SmartScreen warning because this beta installer is not yet code-signed. Install only if you intended to download LV999 from this repository.

After installation, LV999 checks this repository for updates and downloads an available update in the background. Choose **Restart to update** from the LV999 tray menu when convenient.

Source code, development documentation, build logs, local paths, user data, credentials, and provider sessions are not published here.

## Future production signing

Code signing is planned for a later production channel. Until then, releases remain explicitly marked **unsigned beta**.
